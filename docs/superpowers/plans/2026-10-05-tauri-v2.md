## Interfaces and ownership

Core shared types are in tauri/src-tauri/src/model.rs. Rust pdf module exposes info(Path), split_to(source,first,last,temp), merge_to(sources,temp), unlock_to(source,password,temp), validate(Path). All return ForgeResult. No user outputs are written except through transaction/supervisor. Conversions expose word_to_pdf(source,temp), pdf_to_word(source,temp), markdown_to_pdf(source,temp,options) and run_worker(args). Frontend invokes capabilities, select_files, select_output, pdf_info, read_pdf, start_job, cancel_job, get_job, open_folder, log_folder. JobRequest is tagged by kind; job-event uses JobEvent camelCase fields.

## Defaults

Windows x64; full Rust backend; local PDF.js preview. A4 18 mm MD print, per-file output by default, Word timeout 300s, MD 120s, cancellation grace 5s. Documents and diagnostics stay local. Preserve the inherited .NET solution without source changes.
