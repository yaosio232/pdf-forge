# PDF Forge v1.0.5 — PDF to Word（待驗預發佈版）

新增第四個 **PDF to Word** 分頁，將一份完整 PDF 轉成 DOCX。可拖入一份 PDF 或按 Choose PDF 選檔，選擇儲存位置後轉換；成功後可按 **Open output folder** 開啟匯出資料夾。

- 分頁採左側拖放區、右側操作與匯出資訊；仍預設開啟 Split PDF。
- 使用電腦已安裝的 Microsoft Word 桌面版，全程本機轉換。
- 背景 STA 執行，轉換期間停用其他操作並阻止關閉視窗。
- 先產生及檢查暫存 DOCX，再替換指定輸出；轉換失敗不取代既有輸出。

## 使用方式

建議下載 **PDF.Forge-v1.0.5-win-x64.zip**，完整解壓後開啟 `PDF Forge.exe`。ZIP 含 Split Preview 所需的 Poppler 與授權資料；請保留旁邊的 `poppler` 資料夾。

另附 **PDF.Forge.exe** 單檔供下載，但單獨使用此檔不包含 PDF 預覽 renderer；要使用完整分割預覽功能，請使用 ZIP。PDF to Word 功能仍需 Microsoft Word 桌面版。

## 驗證與限制

本版依使用者明確授權直接發佈，**完整 WinForms UI 驗收尚未完成**。SPLIT-01 至 SPLIT-12 與 PDF to Word 的實際拖放、匯出、內容／排版與資料夾操作驗收仍為 **BLOCKED**；不宣稱完整功能驗收通過或 release ready。

Word 可能改變換行、分頁、表格及圖片位置；掃描頁可能仍為圖片，本版未加入 OCR。DOCX 結構檢查不代表內容與排版完整，請自行核對輸出。尚未加入內容差異檢查或 Word 逾時復原。

保留既有 iTextSharp 套件的 NU1701 相容性警告。本版保留在 `codex/pdf-to-word` 分支，未合併 main。
