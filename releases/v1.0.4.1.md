# PDF Forge v1.0.4.1 — 待驗 / Pending validation

本版本為預發佈測試版，來自獨立分支 `codex/v1.0.4.1-pending-validation`，未合併 main。

針對連續載入相同 PDF 的預覽流程：先取消並等待舊背景工作退出，再清理快取；阻止舊回呼更新新畫面；來源內容未變更且已有預覽時重用快取、保留切點。渲染器同步排空輸出管線，取消後等待實際退出。

**待驗：尚未確認 Trend Micro 告警已消除。** Windows UI 擷取與點擊工具受阻，SPLIT-01 至 SPLIT-12 與受影響防毒環境的重載驗收均為 BLOCKED，未通過完整 release gate。

建置及非 UI 測試：33 通過、0 失敗、1 略過（缺少私人原始 PDF 的既有案例）。保留既有 NU1701 相容性警告。單元測試不代表 UI 或防毒驗收通過。

下載單檔 EXE 可替換既有安裝中的程式。PDF 預覽仍需要旁邊的 `poppler` 資料夾；首次使用請下載完整 ZIP 並完整解壓。包裝方式未變更。

請在受影響環境驗證：立即重載相同 PDF、完成預覽後重載、快速切換不同 PDF，以及來源修改／預覽失敗後重新載入。核對來源未變、無殘留渲染程序及防毒事件，並完成標準 40 頁 UI 驗收後再決定合併。
